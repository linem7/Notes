## 安装与首次使用

1. 下载并解压 ZIP，将 `Notes.app` 拖进 **Applications** 后打开。
2. 本版本使用自签名证书，未经过 Apple 公证。首次打开如被拦截，确认下载来源后进入 **System Settings › Privacy & Security › Open Anyway**，再确认 **Open**。不需要自行创建或安装证书。
3. 在 **Settings › Connection** 选择服务商（默认 DeepSeek 模板），输入自己的 API key，点 **Save**。
4. 按 **Option + N** 唤起 Quick Add，开始记第一条 Note。

应用平时显示在菜单栏，首次启动默认开启 **Launch at Login**，可在 Settings 关闭。使用模型需要自己的 API key 和额度。

## 本版功能

- **Board**：固定在桌面上的单列看板，按 Overdue / Today / Upcoming / No Date / Done 分组；On Desktop（像 Stickies 钉在桌面）和 On Top（始终在最前）两种 Board Mode；位置、大小和模式重启后恢复；跨午夜自动重新分组。
- **Quick Add**：Option + N（可改）唤起的浮动面板，不抢前台 app 的焦点，可显示在全屏 app 上方。
- **输入**：粘贴文字、聊天记录；拖入、粘贴或用「+」加入任意文件（含剪贴板图片）；输入框里的链接（最多 5 个）自动识别成 Web Page。
- **Organize**：模型把输入整理成 1–N 条 Draft（标题、截止日期、要点），可逐条修改、取消勾选，再一起保存。「下周三」「明天下午三点」按当前日期换算，读不出截止日期就留空，不编。不开模型思考，追求快。⌘⏎ 可跳过模型，原样保存。
- **本地读取资料**：PDF 抽取文字（扫描版逐页 OCR）、图片 OCR（Apple Vision，中英文）、文本类文件解码、网页由应用自己抓取并抽出正文；Word / Excel / PPT 等只存不读。
- **Material**：原文、文件副本、网页（URL + 正文 + PDF 快照）都保存在本地，执行任务时在 Note 上一键打开。
- **Note 管理**：展开查看 Markdown 格式的 Detail；点 Edit 可编辑 Title、Due Date、Detail，增删 Material；⌘⏎ 或失焦（点别处、切到别的 app）自动保存，Esc 放弃修改；保存失败时 Board 顶部显示红色「Couldn't save」提示并回到修改前的值。勾选完成进入 Done 区；右键 Delete 或选中后按 ⌫ 删除（不弹确认）。同一个文件挂到多条 Note 时本地只存一份。完成超过 30 天的 Note 连同没有其他 Note 使用的文件自动清理。
- **菜单栏**：图标旁显示今天到期 + 已逾期的未完成数量；New Note、Show Board、Board Mode、Settings…、Quit Notes。
- **模型接入**：只支持 OpenAI 兼容协议；DeepSeek（默认，`deepseek-flash`）、OpenRouter、阿里云百炼、Custom 模板；API key 存 macOS Keychain，与 Chatbot 互不共用。可在设置里改 Organize 的 system prompt 并恢复默认。
- **界面语言**：默认英文，可在设置切换简体中文（重启生效）；Note 的语言跟随输入。

## 使用说明与限制

- 不发系统通知，不接日历，不做提醒，不做重复任务。
- 不做搜索、标签 / 分类、拖动排序、多个 Board。
- 不做 iCloud 同步、导出导入。
- 只支持 OpenAI 兼容协议；不支持 Anthropic、Gemini 协议。
- 不读取 Word、Excel、PPT 的内容（只存不读）。
- 不开模型思考，不联网搜索；网页由应用自己抓取。
- 美式键盘上 Option + N 原本用来输入 ñ，注册 Hotkey 后这个组合不再打字，可在 Settings 改键。
- 不包含自动更新或更新检查。升级时退出 Notes，下载新版替换 Applications 中的应用；本地设置、API key 和 Note 保留。
